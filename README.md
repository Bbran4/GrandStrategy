# GrandStrategy

A starter project for Godot **4.7.2 Standard** (no .NET SDK required).

## Open and run

1. Install or extract Godot 4.7.2 from https://godotengine.org/download/archive/4.7.2-stable/.
2. In the Godot Project Manager, choose **Import** and select `project.godot` in this folder.
3. Open the project and press **F6** to run the current scene, or **F5** to run the project.

The main scene is `scenes/main.tscn`. It displays the project title in a resizable
1280 by 720 window using the Compatibility renderer.

Godot records the engine feature version as `4.7` in `project.godot`; use the
4.7.2 editor for this project. The project file does not enforce a patch version.
